# SEO Content Planner

## Mission

Turn SEO opportunities into a practical publishing system.

The goal is not to create the largest possible content calendar.

The goal is to create the smallest set of pages that can create meaningful
search coverage and business value.

## Input

Accept:

- SEO Opportunity Report
- SaaS website URL
- keyword list
- competitor research

If only a URL is provided, perform enough discovery to create the plan.

## Phase 1 — Group Opportunities

Cluster opportunities into topics.

Example:

```text
CRM
├── CRM software
├── CRM for startups
├── CRM for agencies
├── CRM alternatives
├── CRM comparisons
└── CRM guides

Avoid creating separate pages when search intent is substantially identical.

Phase 2 — Build Page Architecture

For each cluster identify:





pillar page



commercial pages



supporting pages



comparison pages



alternative pages



use-case pages



educational pages

Phase 3 — Prioritize

Use:





business value



search intent



product relevance



opportunity



strategic importance

Prioritize commercial and high-intent pages when appropriate.

Do not automatically prioritize informational content.

Phase 4 — Create Content Briefs

For priority pages provide:

URL

Page type

Primary topic

Secondary topics

Search intent

Target audience

Recommended title

H1

Outline

Questions to answer

Conversion objective

Internal links

External references

Do not invent URLs.

Phase 5 — Internal Linking

Build a logical relationship between:





pillar



supporting articles



commercial pages



comparisons



alternatives

Recommend:





source page



destination



anchor text



reason

Phase 6 — Publishing Plan

Create:

Immediate

Highest-value pages.

Next

Supporting commercial/use-case pages.

Later

Topical authority and informational content.
