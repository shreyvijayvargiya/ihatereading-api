# Directory Launch

## Mission

Turn a SaaS product into a **prioritized directory submission strategy**.

Use when the user asks:

> "Find directories where I can submit my SaaS."

> "Launch my SaaS across directories."

> "Get backlinks and traffic from SaaS directories."

Do not produce a giant unfiltered directory list. Prioritize directories based on relevance, visibility, credibility, and effort.

---

## 1. INPUT

### Required

* SaaS website URL

### Optional

* Category
* Target country
* Target audience
* Existing directory list
* Launch deadline
* Free-only requirement

Research the product yourself.

---

## 2. UNDERSTAND THE SAAS

Determine:

* Category
* Product type
* ICP
* Main use cases
* Target industries
* Geography
* Pricing
* Free/trial availability
* Differentiators

Use this information to find relevant directories.

---

## 3. DISCOVER DIRECTORIES

Search for relevant:

* SaaS directories
* Startup directories
* AI directories
* Developer directories
* Product directories
* Industry directories
* Regional directories
* Alternative/comparison databases
* Launch platforms
* Review platforms

Prioritize directories that can provide:

* Referral traffic
* Brand discovery
* Backlinks
* AI/search visibility
* Reviews
* Category authority
* Startup exposure

---

## 4. EVALUATE

Score each directory from 1–5 for:

* Relevance
* Authority
* Traffic/discovery potential
* SEO value
* AI/GEO value
* Submission effort
* Cost/value

Do not invent traffic or authority numbers.

If evidence is unavailable, mark it unknown.

---

## 5. FIND SUBMISSION DETAILS

For high-priority directories identify:

* Submission URL
* Free/paid status
* Required information
* Description requirements
* Category
* Pricing
* Review requirements
* Approval process where discoverable

Prefer official submission pages.

---

## 6. CREATE SUBMISSION DATA

Prepare reusable:

* Short description
* Long description
* Tagline
* Categories
* Features
* Use cases
* Founder/product description
* Social links
* Screenshots/assets needed

Do not fabricate product claims.

---

## 7. OUTPUT

Return:

### Top Directory Targets

| Priority | Directory | Type | Why | Cost | Effort |
| -------- | --------- | ---- | --- | ---- | ------ |

### Submission Checklist

List everything needed before launch.

### Reusable Listing Copy

Create concise product copy that can be adapted to multiple directories.

### Launch Order

**Tier 1:** Submit first

**Tier 2:** Submit next

**Tier 3:** Optional

### Tracking

Recommend tracking:

* submission date
* approval
* URL
* backlink
* referral traffic
* signup/conversion
* review status

---

## QUALITY RULES

* Never invent submission URLs.
* Never claim a backlink is guaranteed.
* Do not recommend irrelevant directories for quantity.
* Prefer quality over hundreds of submissions.
* Flag paid directories clearly.
* Avoid spammy directory networks.
* Verify important submission requirements before recommending them.
