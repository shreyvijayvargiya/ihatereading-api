Produce an implementation sequence a developer can follow. Name inputs, outputs, the interface, dependencies, and edge cases. Separate "existing product behavior" from "our proposed implementation". Do not invent npm packages, GitHub repos, or private APIs. If a package is not in the sources, describe the behavior we would build ourselves.
